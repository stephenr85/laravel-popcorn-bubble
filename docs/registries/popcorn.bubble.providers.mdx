# Bubblewrap language providers

`popcorn.bubble.providers` holds the **language providers** the bubblewrap (`bwrap`) sandbox can
launch. `BwrapRunner` is one runner for every language: when it runs a popcorn `Manifest`, it looks
up the manifest's `runtime` id here, and the matching `LanguageProvider` supplies the interpreter
command line and any extra directories that interpreter needs bound into the sandbox. The runner
supplies everything else: the deny-by-default sandbox floor, the grant's flags and the resource limits.

## What ships

Two providers, registered the first time the registry is read:

- **`node`** (`NodeProvider`) runs `node /pkg/<entrypoint>`.
- **`python`** (`PythonProvider`) runs `python3 -I /pkg/<entrypoint>` (isolated mode, so host site directories are ignored), and binds the C-extension wheel
  directories that live outside `/usr`.

An interpreter installed under `/usr` needs no extra binds, because the sandbox floor already binds
`/usr` read-only.

These ids are separate from the wasm runner's (`javy`, `python-wasi`): choosing a runtime id also
chooses the sandbox it runs in.

## Adding or replacing a provider

Implement `LanguageProvider` (`runtimeId()`, `argv()`, `extraBinds()`, `probe()`) and register it. It
keys itself by `runtimeId()`. The most common use is pointing a shipped runtime at a different
interpreter, such as a Node installed by nvm outside `/usr`:

```php
use Rushing\Popcorn\Bubble\BwrapRunner;

$this->app->make(BwrapRunner::class)->register(new NvmNodeProvider('/opt/node/bin/node'));
```

Because its `runtimeId()` is `node`, it replaces the shipped provider, and its `extraBinds()` must
bind the interpreter's directory, since that directory isn't under `/usr`.

## Lookups and misses

`providerFor($id)` strips a version suffix before looking up, so a manifest asking for `node@22`
finds `node`. A manifest naming a runtime nobody registered doesn't throw: the run returns a
substrate-unavailable `Result`, as it does when `bwrap` isn't installed or the provider's `probe()`
reports the interpreter missing. `runtimeIds()` lists what's registered.

## Duplicates

The policy is **supersede**: registering a provider under a taken id replaces it. That's the
intended way to swap an interpreter, not an accident.
